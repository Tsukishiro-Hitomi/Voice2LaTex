# 首行注释里的课程名会被读出来显示，所以建议照着「课程名 术语表」写。
# 想要一份不指定 --glossary 时默认生效的，把它拷成仓库根目录的 glossary.txt。

# —— 「错的=>对的」：把左边的识别错误纠正成右边 ——
# ASR 听错的词写在左边。这类条目最有价值，也只能靠上课攒。
行列是=>行列式
移向=>移项
承位矩阵=>单位矩阵
特正值=>特征值

# 希腊字母和符号：口述的字母 ASR 常拼错，统一还原成 LaTeX 写法
lambda=>\lambda
that=>det

# —— 不带 => 的是白名单：告诉模型这个词该怎么写 ——
# 没听错、但模型可能写成同义词或换个说法的术语写在这里。
特征值
特征向量
特征方程
行列式
方阵
线性无关

# 1. 看到笔记里术语错了就往下补一条，这是唯一需要长期维护的东西。
# 2. 文科课比理科更依赖术语表：理科术语被上下文强约束，模型能反推；
#    人名、地名、书名推不出来，务必第一次提到就补进去。
# 3. 每份术语表几百 tokens，对成本的影响可以忽略，不必吝惜条目。
